# CoA — 17.000+ objetos para WoW 3.3.5a

Descarga los archivos de la sección **Releases** del repositorio. Este paquete incluye ocho MPQ preparados para copiar directamente al cliente y un SQL opcional para administradores de servidores.

## Instalación

1. Cierra World of Warcraft.
2. Descarga los **ocho archivos MPQ** de la misma Release.
3. Copia los ocho archivos directamente en la carpeta `Data` de tu cliente WoW 3.3.5a.
4. Abre el juego y disfruta.

**No renombres los MPQ:** los archivos de la Release deben venir ya con los nombres correctos.

Si Windows pregunta si quieres reemplazar un archivo existente, cancela y consulta antes. No borres ni reemplaces `patch-NAI.MPQ`. No modifiques la carpeta `Cache`.

## SQL opcional

`item_template.sql` es opcional y está destinado a administradores de servidores. **No lo necesitas para jugar con los MPQ.** No lo importes sin revisar su compatibilidad con tu core y base de datos.
